### Проблемний аналіз існуючих програмних продуктів (2.3.2)

Аналіз існуючих програмних продуктів (не менше 3х), які частково задовольняють інформаційні потреби, представлений у форматі, подібному до Таблиці 3:

| Назва Продукту | Інформаційна Потреба, яку задовольняє | Переваги (Strengths) | Недоліки / Прогалини (Gaps) |
| :--- | :--- | :--- | :--- |
| **Udemy / Coursera** | 24. Навчання, отримання знань | Широкий вибір курсів, гнучкий графік, можливість отримати сертифікати. | Відсутність персоналізованої траєкторії під статус (17); складнощі з верифікацією якості курсів. |
| **Monobank / Sense SuperApp** | 12. Фінансова захищеність | Зручний інтерфейс, інструменти для бюджетування та накопичень, кешбек. | Не надають глибинних аналітичних інструментів для складного інвестування; фокус на базових потребах. |
