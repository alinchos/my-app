### Цільова аудиторія споживачів програмного продукту (2.3.4)

Цільова аудиторія продукту — це **амбітні професіонали, орієнтовані на статус та фінансову ефективність**.

**1. Демографічні параметри:**

| Параметр | Опис |
| :--- | :--- |
| **Вік** | 25 – 40 років |
| **Освіта** | Вища або незакінчена вища, прагнення до постійного самовдосконалення |
| **Дохід** | Середній або вище середнього (мають кошти для інвестицій, але шукають оптимізації) |
| **Професія** | Фахівці у сфері ІТ, фінансів, консалтингу, менеджери середньої ланки, підприємці |
| **Географія** | Міські жителі великих та середніх міст |

**2. Психографічні та поведінкові характеристики:**

* **Мотивація:** Прагнення до швидкого підвищення соціального статусу та визнання у професійних колах.
* **Споживання:** Свідоме, орієнтоване на якість та довгострокову цінність (якісний одяг, перевірені інвестиції).
* **Проблема:** Відчувають брак часу та знань для інтеграції фінансового планування, навчання та іміджу в єдину ефективну стратегію.
